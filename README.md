# SimpleRadar

A simpler MyRadar-style weather app: live animated radar, current conditions, a 7-day forecast, and National Weather Service alerts.

Live app: https://gsn-lgtm.github.io/simpleradar/

Repo: https://github.com/gsn-lgtm/simpleradar

Default view is Hoover / Birmingham, Alabama. Tap the crosshair for your location, or search any city.

## Use it on iPhone

1. Open https://gsn-lgtm.github.io/simpleradar/ in Safari.
2. Tap Share → **Add to Home Screen**.
3. Open SimpleRadar from the home screen like a normal app.

## What it shows

- 24-hour US NEXRAD radar (Iowa State mosaic)
- Optional 2-hour worldwide loop (RainViewer)
- Current conditions and 7-day forecast (Open-Meteo)
- Active NWS alerts in the United States
